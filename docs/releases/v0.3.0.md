# Dots Agent Bridge v0.3.0

- Added opt-in Agent Dispatch so a Dot can submit a task to an explicitly allowed OpenBot agent and read its eventual result. Dispatch requires the separate `bridge:dispatch` scope and a configured target.
- Task status now shows transient OpenBot unavailability while the bridge retries the same task; it does not require resubmission.
- Added an [importable Dots chat wrapper for OpenBot](https://github.com/Coke1120/Dots-Agent-Bridge/blob/v0.3.0/docs/openbot-dots-wrapper.md). It uses the existing HTTP MCP mailbox and does not require a separate Docker container if the existing Bridge is reachable.

Dispatch and the wrapper are optional. The wrapper is model-mediated, requires the configured OAuth connection and event subscription, and does not support unsolicited chat pushes or native ChatGPT transcript sync. Live OpenBot import, OAuth sign-in, and end-to-end message delivery remain deployment checks. Publishing this release does not deploy or change any host.
