# Dots Agent Bridge v0.2.1

- Process ready webhook deliveries without an artificial delay between callbacks. Failed deliveries get their full retry backoff starting when the attempt finishes.
- Reserve room for a closing response so progress updates cannot leave a conversation stuck.
- Allow retired webhook slots to be reused without reviving old deliveries.
- Read request responses through an indexed, bounded page.
- Document the fixed-domain OAuth deployment for OpenBot in Docker and how to verify its discovery and audience.

The response index is added when the existing database opens. Keep the database and encryption key together and back them up before upgrading. Publication does not deploy the bridge. A live OpenBot ↔ Dots OAuth sign-in and synthetic round trip remain deployment checks.
